# LiteWASM

LiteWASM is a WIP WebAssembly runtime. The end goal of LiteWASM is to provide a lightweight WASM runtime for interpreting and executing the WebAssembly format.

LiteWASM aims to be a learning experience, but in the future, it may evolve into a usable WebAssembly runtime.

> [!WARNING]
> This project is unfinished and has not yet achieved its original aim. It is not ready for practical use.
